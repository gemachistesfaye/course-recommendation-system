# Personalized Course Recommendation System

An end-to-end Machine Learning project for personalized technology course recommendations.

## Project Structure
- ml/data/raw/: Raw datasets (users.csv, courses.csv, interactions.csv)
- ml/notebooks/: EDA & interaction matrix notebook
- ml/src/preprocessing/: Reusable data loader & baseline recommender
- ml/tests/: Automated unit tests
- docs/: Documentation suite
